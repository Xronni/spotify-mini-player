# 🎵 Spotify Mini Player (Linux / GTK4 + Libadwaita)

Эстетичный, полупрозрачный мини-плеер и всплывающий OSD-виджет для Spotify под Linux (X11 / GNOME). Выполнен в тёмной теме с поддержкой двусторонней синхронизации MPRIS, отображением реальной очереди треков из Spotify, регулятором громкости и автоматической локализацией.

---

## ✨ Основные возможности:

1. **📋 Настоящая очередь треков Spotify (Queue Drawer)**:
   - Считывание и парсинг реальной очереди воспроизведения и контекста напрямую из локального хранилища Spotify (LevelDB).
   - Отображение точного названия текущего плейлиста или альбома в заголовке очереди.
   - Секции: **«Ранее играли»** (история треков плейлиста до текущего), **«Сейчас играет»** (с возможностью перезапуска трека) и **«Следующие в очереди»**.
   - Настоящая сквозная нумерация треков из плейлиста.
   - Плавная прокрутка: текущий трек автоматически центрируется при открытии очереди.
   - Быстрый запуск любого трека по клику без раскрытия главного окна Spotify.

2. **🌍 Автоматическая локализация (i18n)**:
   - Автоматическое определение языка интерфейса Spotify (`ru`, `en`, `de`, `es`, `fr`).
   - Мониторинг настроек в реальном времени: при смене языка в Spotify мини-плеер бесшовно перезапускается с обновленным языком интерфейса.

3. **🔊 Синхронизация громкости в реальном времени**:
   - Двусторонняя синхронизация ползунка громкости и статуса Mute/Unmute со Spotify.
   - Регулировка громкости колесиком мыши над плеером или иконкой громкости.

4. **👁️ Режим умного всплывающего виджета (OSD HUD)**:
   - Плеер автоматически плавно появляется на экране при переключении треков или паузе глобальными горячими клавишами.
   - Если окно Spotify открыто на экране, мини-плеер автоматически скрывается и не дублирует интерфейс.
   - Через 3.5 секунды окно плавно исчезает, если на него не наведён курсор мыши.
   - **📌 Закрепление (Pin)**: кнопка закрепления фиксирует плеер поверх всех окон.

5. **🫧 Эстетичный дизайн и визуализатор**:
   - Полупрозрачный стеклянный фон (`rgba(18, 18, 22, 0.85)`) со скруглениями и мягкой тенью.
   - Анимированный звуковой визуализатор в такт воспроизведению.
   - Интерактивный прогресс-бар с точной перемоткой.

---

## 🚀 Установка и запуск

### Требования:
- Python 3.10+
- GTK 4, Libadwaita, PyGObject (`python3-gi`, `gir1.2-gtk-4.0`, `gir1.2-adw-1`)
- Spotify Desktop для Linux

### Запуск:
```bash
./run.sh
```
